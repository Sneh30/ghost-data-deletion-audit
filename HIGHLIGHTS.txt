THE DIFFERENTIATOR
Instead of asking a model to infer whether data was deleted, this agent reconstructs
the state from participant-visible evidence and proves every emitted step.

- Deterministic at inference: 0 model calls, 0 network calls, $0.00 API cost. The same
  518-row CSV is reproducible from source.
- Claims are not evidence: reported_status and system_activity.reported_result are
  ignored as truth. Each resource state comes from logs, SQL snapshots, PDFs, OCR'd
  screenshots, and audit records.
- Time-travel correct: a fact is citable only when its evidence file was captured at or
  before audit_at. Late-captured facts can guide discovery and future verification, but
  are never used as FINDING citations.
- Complete remediation: every INCOMPLETE case carries findings with evidence, the full
  ordered remediation plan, and the future checks that must pass.
- Evidence discipline: every COMPLETE verification cites real evidence. The agent does
  not invent evidence IDs to chase a sample score.
- Reproducible packaging: code.zip includes source, prompts, tests, tools, and evaluation
  reports, excludes the dataset, and its packaged run is byte-identical to output.csv.

HARD PARTS THIS HANDLES
- Multilingual intent: deletion versus access, correction, export, or opt-out, so
  non-deletion requests become NOT_APPLICABLE with no invented steps.
- Identity resolution: current and historical email, phone, email hash, and stable user_*
  IDs; names are never used for matching.
- Temporal integrity: capture time versus observation time, a 7-day citation window, and
  late evidence handled separately from findings.
- Evidence breadth: SQL snapshots, application logs, JSON, PDFs, text handovers, and
  screenshots through local macOS Vision OCR, cached by file hash.
- Policy breadth: delete, redact, anonymize, retain, and account tombstones, with ordered
  remediation that disables flows and blocks restores before dependent records.
- Auditability: canonical JSON, contiguous step numbers, the exact seven-key schema, and
  a hard validator that rejects malformed output.
